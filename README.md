The main CPP file is located in "src" and is called "main.cpp" -

(Explanation about the client will be in the client README)

This file includes a server program (built in a low end coding language C++) that can be & was uploaded to a micro controller.
Such as an "ESP32", which is able to communicate along with a computer using wifi.
This side of the program receives data from the client side and turns that data to real world inputs.
Like changing the angle of the servo
And changing the (simulated) throttle to make the car move (in simulation).

============================================================================
The purpose of this project is to demonstrate successful communication between a server and an infinite amount of clients.
These are built in two different coding languages and run on two completely different types of computers.
Communicating over wifi to apply results as real-world data and movement.
